# Aria AI v0.2

وب‌اپلیکیشن فارسی و قابل نصب روی اندروید (PWA).

## انتشار رایگان با GitHub Pages
1. فایل‌های این بسته را در ریشه مخزن `aria-ai` بارگذاری کن.
2. در مخزن وارد Settings و سپس Pages شو.
3. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کن.
4. شاخه `main` و پوشه `/(root)` را انتخاب و Save کن.
5. پس از انتشار، آدرس GitHub Pages را در Chrome اندروید باز کن و از منوی مرورگر Add to Home screen را بزن.

## امکانات نسخه فعلی
- رابط گفتگوی فارسی و راست‌چین
- ذخیره محلی تاریخچه
- ورودی گفتار فارسی در مرورگرهای پشتیبانی‌شده
- امکان تنظیم API سازگار با OpenAI Chat Completions

## محدودیت و امنیت
این نسخه خودش مدل زبانی، جست‌وجوی زنده وب یا عامل خودمختار ندارد. برای پاسخ هوشمند باید سرویس مدل جداگانه پیکربندی شود. کلید API در localStorage مرورگر ذخیره می‌شود و برای انتشار عمومی امن نیست؛ برای محصول واقعی باید backend امن ساخته شود. رایگان‌بودن مدل و محدودیت مصرف به ارائه‌دهنده بستگی دارد.
